# IBM-Data-Science


This is my complete **Capstone Project** for the **IBM Data Science Professional Certificate** from Coursera, which uses data from **SpaceX**. As a member of the **Columbia Space Initiative Rockets Team**, I have a deeper, personal connection to this project.

Initially, I leveraged some established techniques due to time constraints, but I've since been independently updating and refining the project. I'll continue to do so until I'm fully satisfied with the results.
